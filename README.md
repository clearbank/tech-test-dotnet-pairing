# .NET Pairing Exercises

This repository contains two pairing exercises. You will be told which exercise to prepare for ahead of your session.

- [Bank Account](BankAccount/) — a single-file console app (.NET 10)
- [Payment Engine](PaymentEngine/) — a multi-file solution with unit tests (.NET 10)

Please familiarise yourself with the exercise code **before** the session. The pairing session will be guided — we will work together to extend and improve the existing code.
